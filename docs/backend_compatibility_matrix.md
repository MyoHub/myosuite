# Backend support

CPU Gymnasium and mjlab (Warp) are the supported pair under one `env_id`.
MJX is experimental.

- Contract: [docs/wiki/cross-backend-contract.md](wiki/cross-backend-contract.md)
- Parity tests: `pytest myosuite/tests/test_parity.py` (`atol=1e-6`)
- Sphinx: [docs/source/backend_parity.rst](source/backend_parity.rst)
