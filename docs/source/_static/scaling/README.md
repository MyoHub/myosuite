# Native validation research outcomes

`native_validation_metrics.json` retains aggregate validation errors and counts,
protocol settings, source hashes and scientific citations. Original native
models, pose/shape parameters, coordinates, marker trials, individual scale
vectors and motion exports remain local. This report does not grant a licence
to redistribute source models, datasets or derived geometry and motion assets.
