# Keast validation plot

`keast_validation.png` is a new plot of scalar errors computed in
`myosuite/tests/data/anatomy_scaling/keast_landmark_validation.json`. It contains
no source anatomy rendering or coordinates and is distributed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), separately from the
Apache-2.0 implementation.

Credit Keast, Bonacci and Fox (2023),
[doi:10.7717/peerj.14708](https://doi.org/10.7717/peerj.14708),
[Figshare version 4](https://doi.org/10.6084/m9.figshare.20454462.v4), and the
Nolte MRI cohort,
[doi:10.5281/zenodo.167808](https://doi.org/10.5281/zenodo.167808) and
[doi:10.1016/j.jbiomech.2016.09.005](https://doi.org/10.1016/j.jbiomech.2016.09.005).
The changes are the integration's own fitting protocol, computed errors and
plot; it does not reproduce the source SSM reconstruction experiment.
