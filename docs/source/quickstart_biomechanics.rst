Biomechanics Quick Start
=========================

This guide is for biomechanists who want to use MyoSuite to run forward simulations,
extract kinematic and kinetic data, perform inverse dynamics, and interface with
tools like OpenSim.

No machine learning background is required.

.. contents:: Contents
   :local:
   :depth: 2

Key Concepts
------------

MyoSuite simulates musculoskeletal models in `MuJoCo <https://mujoco.org/>`_.
A few terms you will encounter:

* **MjData** — the simulation state at the current time step (positions, velocities, forces).
* **qpos** — generalised joint positions (angles in radians for rotational joints).
* **qvel** — generalised joint velocities (rad/s).
* **actuator_force** — net force/torque generated by each muscle actuator (N or N·m).
* **Frame skip** — number of physics sub-steps per control call (default 10 × 2 ms = 20 ms control period).

Running a Forward Simulation
------------------------------

.. code-block:: python

   import gymnasium as gym
   import myosuite
   import numpy as np

   env = gym.make('myoElbowPose1D6MRandom-v0')
   obs, info = env.reset(seed=0)

   # Access the underlying MuJoCo model and data
   model = env.unwrapped.model  # mujoco.MjModel
   data  = env.unwrapped.data   # mujoco.MjData

   print("Number of joints:  ", model.njnt)
   print("Number of muscles: ", model.nu)
   print("Joint names:       ", [model.joint(i).name for i in range(model.njnt)])

   obs, info = env.reset()
   for _ in range(100):
       env.step(env.action_space.sample())  # random muscle excitations

   env.close()


Extracting Kinematics
----------------------

.. code-block:: python

   import gymnasium as gym
   import myosuite
   import numpy as np

   env = gym.make('myoElbowPose1D6MRandom-v0')
   obs, info = env.reset(seed=0)

   records = []
   for _ in range(500):
       obs, reward, terminated, truncated, info = env.step(env.action_space.sample())
       d = env.unwrapped.data
       records.append({
           "time":    d.time,
           "qpos":    d.qpos.copy(),    # joint angles (rad)
           "qvel":    d.qvel.copy(),    # joint velocities (rad/s)
           "xpos":    d.xpos.copy(),    # body Cartesian positions (m)
       })
       if terminated or truncated:
           obs, info = env.reset()

   # Summarise range of motion
   qpos_array = np.array([r["qpos"] for r in records])
   rom = np.ptp(qpos_array, axis=0)  # peak-to-peak per joint
   model = env.unwrapped.model
   for i, r in enumerate(rom):
       print(f"  {model.joint(i).name:30s}  ROM = {np.degrees(r):.1f} deg")

   env.close()


Extracting Muscle Forces
-------------------------

``data.actuator_force`` contains the net force/torque each actuator exerts
(muscle force projected through moment arms, in N or N·m):

.. code-block:: python

   import gymnasium as gym
   import myosuite
   import numpy as np

   env = gym.make('myoElbowPose1D6MRandom-v0')
   obs, info = env.reset(seed=0)

   force_records = []
   for _ in range(500):
       obs, reward, terminated, truncated, info = env.step(env.action_space.sample())
       force_records.append(env.unwrapped.data.actuator_force.copy())
       if terminated or truncated:
           obs, info = env.reset()

   forces = np.array(force_records)
   model = env.unwrapped.model
   print("Peak muscle forces (N):")
   for i in range(model.nu):
       print(f"  {model.actuator(i).name:30s}  {forces[:, i].max():.1f}")

   env.close()


Inverse Dynamics
-----------------

MyoSuite includes a tutorial for computing joint torques from motion data.
See ``tutorials/6_Inverse_Dynamics.ipynb`` for a step-by-step walkthrough.

The key MuJoCo function is ``mujoco.mj_inverse(model, data)``, which fills
``data.qfrc_inverse`` with the generalised forces required to produce the
observed acceleration:

.. code-block:: python

   import mujoco
   import numpy as np

   # After setting data.qpos, data.qvel, data.qacc:
   mujoco.mj_inverse(model, data)
   joint_torques = data.qfrc_inverse.copy()  # N·m per generalised coordinate

Replaying OpenSim Motion Files
-------------------------------

MyoSuite can play back ``*.mot`` files exported from OpenSim.
See ``tutorials/10_PlaybackMotFile.ipynb`` for the full workflow.

The high-level steps are:

1. Load the motion file (column headers map to joint names).
2. Iterate over frames, setting ``data.qpos`` to the corresponding angles.
3. Call ``mujoco.mj_forward(model, data)`` to update all derived quantities.
4. Extract whatever quantities you need (muscle forces, contact forces, etc.).


Body Centre of Mass and Ground Reaction Forces
-----------------------------------------------

.. code-block:: python

   import mujoco

   mujoco.mj_forward(model, data)

   # Subtree centre of mass for the whole body (world frame)
   com = data.subtree_com[0].copy()   # shape (3,)

   # Contact forces (all contacts)
   for i in range(data.ncon):
       contact = data.contact[i]
       force_torque = np.zeros(6)
       mujoco.mj_contactForce(model, data, i, force_torque)
       print(f"Contact {i}: force = {force_torque[:3]} N")

Pathological Conditions
------------------------

Variant environments model common clinical conditions:

.. code-block:: python

   import myosuite, gymnasium as gym

   # Sarcopenia: 50 % reduction in peak muscle force
   env = gym.make('myoSarcElbowPose1D6MFixed-v0')

   # Cumulative fatigue: activation history reduces muscle output
   env = gym.make('myoFatiElbowPose1D6MFixed-v0')
