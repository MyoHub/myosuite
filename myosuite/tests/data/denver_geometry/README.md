# Derived Denver tissue validation

`validation.json` contains aggregate geometry checks and input hashes, without
source meshes, spreadsheets or per-geometry source volume rows. The computed
report is released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/),
separately from the Apache-2.0 implementation. The original archive READMEs
request attribution to both Andreassen et al.,
[Scientific Data (2023)](https://doi.org/10.1038/s41597-022-01905-2), and the
[overclosure study](https://doi.org/10.48550/arXiv.2209.06948).
The [University of Denver Visible Human dataset](https://digitalcommons.du.edu/visiblehuman/)
is identified by [doi:10.56902/COB.vh.2022.0](https://doi.org/10.56902/COB.vh.2022.0).

The changes are computed mesh/table consistency summaries, quality counts and
source hashes; no original geometry or table is reproduced. Retain the
attribution, licence link and change description when sharing the report.
Sources and report are supplied without warranties; see the
[CC BY 4.0 legal terms and disclaimer](https://creativecommons.org/licenses/by/4.0/legalcode.en).
No endorsement is implied. See [`THIRD_PARTY_DATA.md`](../../../../THIRD_PARTY_DATA.md)
for the full artifact inventory and source notices.

The original data remain local. These are the same two Visible Human donors
used by BoneHub, not additional population subjects. Volume-table consistency
does not establish muscle parameters or anatomical accuracy after scaling.
