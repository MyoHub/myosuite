# YCB_sim (subset)

The `009_gelatin_box` object used by `myoChallengeBimanual-v0`, copied from
[MyoHub/YCB_sim](https://github.com/MyoHub/YCB_sim) `v0.2.0` (Apache-2.0, see `LICENSE`).
Only the files the MyoSuite environments load are kept. The texture was downsized from
4096x4096 to 1024x1024 (exact 75-colour palette, sRGB chunk kept); the rest is unmodified.
